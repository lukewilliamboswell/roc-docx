# Security policy

Only the latest published release and the current `main` branch are
supported. Fixes land on `main` and ship in the next release.

Report a suspected vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/lukewilliamboswell/roc-docx/security/advisories/new),
not in a public issue, discussion or pull request. Include the affected
release or commit, the impact, and a minimal document or input that reproduces
it. Documents are untrusted input to this package, so a crash, hang or
unbounded resource use on any `.docx` is in scope.

The maintainer aims to acknowledge a report within 3 business days and to
agree a disclosure timeline with the reporter, normally within 90 days.
