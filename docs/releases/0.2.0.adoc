= roc-docx 0.2.0

This release updates the package and examples for the current Roc compiler.
It crosses the pre-1.0 compatibility boundary because the current compiler
cannot compare the public API of the previous release.

== Upgrade an application

Update the package URL and use a platform compatible with your compiler.
The maintained command-line examples use basic-cli 0.28.1:

[source,roc]
----
app [main!] {
	cli: platform "https://github.com/roc-lang/basic-cli/releases/download/0.28.1/7brgwR8YUqfeGrkdfF1V4GPPN7DnP7ftqub9KcrTEZtr.tar.zst",
	docx: "{package-url}",
}
----

Command-line entry points take `List(OsStr)`; convert arguments directly to
paths with `Path.from_os_str`.

== Compiler and dependency compatibility

An explicit type on the style-toggle helper supports the newer compiler's
inference, and local names no longer shadow module declarations. The
roc-zip 0.3.0-rc3 dependency exposes its signature types through `Zip` for
Roc's import visibility checks. It uses CRC32 2.0.1. The XML dependency is
roc-parser 6.0.0-rc.3.1, which keeps short XML lexemes inline.

Repository tooling pins `roc-stable` to `nightly-2026-11-18-a520eed`
and uses basic-cli 0.28.1 and roc-fuzz 0.7.0. The package itself carries
no compiler pin. The browser playground uses Signals 0.6.0 and its matching
runtime, with explicit reporting of worker payload failures.
Its Blueprint tasks select specialization on the November 22 nightly to
work around https://github.com/roc-lang/roc/issues/13372[Roc issue #13372].
